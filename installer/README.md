# Antigravity Multi-Agent Framework - 1-Click Installer

Paket instalasi otomatis portabel lintas perangkat untuk macOS dan Linux.

## Cara Install di Device Baru:
1. Clone atau copy folder ini ke komputer baru:
   ```bash
   git clone <repo-url> ~/agent-framework
   cd ~/agent-framework
   ./installer/install.sh
   ```
2. Verifikasi instalasi:
   ```bash
   ./installer/verify.sh
   ```
3. Langsung gunakan:
   ```bash
   team-orch status
   ```
